# KrishiSetu 🌾

**Empowering Indian Farmers with Credit and Commerce**

KrishiSetu is a modern web platform that bridges the gap between farmers, vendors, and banks — enabling them to sell crops, access credit, and purchase agricultural essentials easily and securely.

🌐 **Live Preview**: [KrishiSetu Landing Page](https://v0-krishi-setu-landing-page-tctfa4.vercel.app/)

## 🖼 Pages Implemented

- **Landing Page** – Clean, informative homepage with CTAs
- **Signup Page** – User registration interface
- **Farmer Dashboard** – Displays farmer profile, recent activity, and navigation

> Full integration with backend services and state management is currently in progress.

---

## 🧑‍🌾 Target Users

- **Farmers** – Sell produce, track earnings, and access loans  
- **Vendors** – Buy produce directly from farmers  
- **Banks** – Provide credit scores and financial access
